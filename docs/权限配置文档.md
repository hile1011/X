# 权限配置文档

> 版本：V0.22（对应数据库迁移 v30）　更新日期：2026-09-11
> 本文是系统 RBAC 权限体系的完整配置参考，涵盖权限目录、模块权限映射、角色配置与前后端验证机制。

## 一、权限体系架构

系统采用 **RBAC（基于角色的访问控制）** 模型，数据流：

```
用户 ──多对多──> 角色 ──多对多──> 权限（权限码）
```

- 权限码格式：`模块:操作`，如 `quotes:edit`
- 用户登录后 JWT 携带用户标识，后端实时查询权限（30s 缓存）附加到 `req.permissions`
- 前端通过 `usePermission()` Hook（`src/hooks/usePermission.ts`）读取权限集合
- **双重校验**：前端控制 UI 展示（菜单/按钮/只读态），后端中间件强制拦截 API（防止越权）

### 后端验证中间件（api/middleware/auth.ts）

| 中间件 | 语义 |
|---|---|
| `authenticate` | 验证 JWT，附加 `req.user` 与 `req.permissions` |
| `requirePermission(code)` | 必须持有指定权限码，否则 403 |
| `requireAnyPermission(...codes)` | 持有任一权限码即可通过 |
| `requireRole(code)` | 必须拥有指定角色编码 |

## 二、业务模块权限映射（v30 新增）

### 做货跟踪（/production-tracking）

| 权限码 | 名称 | 类型 | 控制点 |
|---|---|---|---|
| `production-tracking:view` | 做货跟踪-查看 | menu | 菜单显示、路由进入、`GET /quotes/production-tasks/overview`、`GET /quotes/:id/production-tasks` |
| `production-tracking:edit` | 做货跟踪-编辑 | button | 任务新增/修改/删除/移动/一键排期/拖拽排期、`PUT /quotes/:id/production-tasks` |

> 说明：`GET/PUT /quotes/:id/production-tasks` 同时被订单详情页「做货流程 Tab」使用，故采用 `requireAnyPermission('production-tracking:view', 'quotes:view')` / `('production-tracking:edit', 'quotes:edit')`，两条路径任一满足即可，与升级前行为完全兼容。

### 订单对账管理（/reconciliation-alerts）

| 权限码 | 名称 | 类型 | 控制点 |
|---|---|---|---|
| `reconciliation:view` | 订单对账-查看 | menu | 菜单显示、双列表/详情页路由、`GET /quotes/:id/reconciliation-costs` |
| `reconciliation:edit` | 订单对账-编辑 | button | 工艺成本明细录入/保存、`PUT /quotes/:id/reconciliation-costs` |
| `reconciliation:execute` | 订单对账-执行 | button | 确认对账（5→8）、退回对账（8→5）、`POST /quotes/:id/reconcile`、`POST /quotes/:id/unreconcile` |

### 年度业务报表（/annual-report）

| 权限码 | 名称 | 类型 | 控制点 |
|---|---|---|---|
| `annual-report:view` | 年度业务报表-查看 | menu | 菜单显示、路由进入 |

> 年度业务报表页数据来源于订单列表（`quotes:view`），为管理员配置财务类角色时建议同时授予 `annual-report:view` + `quotes:view`。

## 四、角色权限配置指南

### 内置角色

- **系统管理员（admin）**：持有全部 50 项权限，不可删除。

### 推荐自定义角色模板

| 角色 | 建议权限组合 |
|---|---|
| 业务员 | `dashboard:view` + `quotes:view/create/edit/copy/export/print` + `production-tracking:view/edit` + `customers:view` + `products:view` |
| 生产管理员 | `dashboard:view` + `quotes:view` + `production-tracking:view/edit` |
| 财务 | `dashboard:view` + `quotes:view` + `reconciliation:view/edit/execute` + `annual-report:view` + `quotes:export-payment` |
| 只读观察者 | `dashboard:view` + `quotes:view` |

### 配置入口

1. **角色管理**（/roles）：新建/编辑角色 → 按模块勾选权限（含 v30 新增的「做货跟踪」「订单对账管理」「年度业务报表」模块卡片）
2. **用户管理**（/users）：为用户分配一个或多个角色，权限取并集
3. **权限管理**（/permissions）：查看全部权限目录及归属角色数

### 权限变更生效性

- 后端权限查询带 **30 秒缓存**，角色权限调整后最迟 30 秒内全量生效（缓存过期自动刷新）
- 前端菜单/按钮随权限实时渲染，无需重新登录（权限缓存刷新后自动更新）

## 五、存量角色升级兼容（v30 迁移）

迁移 `v30-add-business-module-permissions` 自动执行存量分配，保证升级后既有角色行为零回退：

| 原持有权限 | 自动获得 |
|---|---|
| `quotes:view` | `production-tracking:view`、`reconciliation:view` |
| `quotes:edit` | `production-tracking:edit`、`reconciliation:edit` |
| `quotes:status-transition` | `reconciliation:execute` |
| `reports:view` | `annual-report:view` |

升级后管理员可在角色管理中按需收回（例如仅保留财务角色的对账权限，收回其订单编辑权限）。
