VTable HTTP 复制 Bug 复现

当前环境检测：
检测项值
window.isSecureContext
navigator.clipboard
ClipboardItem
protocol
hostname

要复现 Bug，isSecureContext 必须为 false（即通过 HTTP + 非 localhost 访问）。
如果显示 true，请改用 http://<本机IP>:端口/vtable-bug-repro.html 访问。

复现步骤：
  1. 在下方表格中点击任意一个单元格（单单元格选中）
  2. 按 Ctrl+C（或 Cmd+C）复制
  3. 点击下方文本框，按 Ctrl+V 粘贴
  4. 观察粘贴结果 —— 如果文本框为空，说明复制失败（Bug 已复现）

粘贴测试区

说明：
此 Bug 的根因是 VTable 的 handleCopy 是 async 函数，内部有 yield setTimeout(10) 异步等待。在 HTTP（非安全上下文）下 navigator.clipboard 不可用，fallback 路径中的 e.clipboardData.setData() 在 async 之后已失效（浏览器只在同步事件分发期间允许写入）， document.execCommand('copy') 也因失去用户手势上下文而失败。
