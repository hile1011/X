## 六、边界条件覆盖

1. **越权防护**：仅持 `quotes:view` 的角色不获得任何模块编辑/执行权限（迁移测试"不越级"断言）
2. **双路径兼容**：仅持 `quotes:edit`（无模块权限）的存量用户仍可编辑订单详情页做货 Tab（`requireAnyPermission`）
3. **权限变更实时性**：rbac 缓存失效测试验证角色权限调整后查询结果即时更新（30s 缓存窗口）
4. **回滚安全**：v30 down 完整清理 role_permissions → permissions（外键顺序），不影响 v29 及以下数据
5. **幂等重放**：升级脚本重复执行不产生重复权限行或重复角色关联
