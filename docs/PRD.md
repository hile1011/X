## 1. 产品概述

### 1.1 产品名称
帆布袋报价跟单系统（Quote Order System）

### 1.2 产品定位
面向帆布袋生产企业的 B 端管理工具，覆盖从报价试算、打样、大货生产到发货收款的全流程跟单管理。

### 1.3 核心价值
- **报价效率**：内置 6 种帆布袋款式的专用报价模板，通过在线表格公式引擎自动计算成本与卖价
- **流程管控**：订单状态流转（报价→打样→做货→发货→收款→结束），关键节点自动记录时间
- **数据沉淀**：客户、产品、工艺成本统一管理，仪表盘实时呈现经营数据

### 3.2 订单管理

#### 3.2.1 订单列表

**路径**：`/quotes`

| 功能项 | 说明 |
|---|---|
| 订单列表 | 展示所有报价/订单，含订单号、客户、款式、状态、金额 |

#### 3.2.2 订单报价编辑页

**路径**：`/quotes/new`、`/quotes/:id`、`/quotes/:id/edit`

**页面结构**（自上而下）：
1. 顶栏：返回列表 / 保存 / 重置
2. 订单状态流转：6 节点 + 箭头，支持前进/退回/结束
3. 做货流程（仅做货中状态显示）：6 步骤（面料采购→裁剪→印刷→缝纫→质检→包装）
4. 订单信息卡片：
   - 单个卖价（不含税[红] / 含税[蓝]，可编辑）
   - 表单字段：客户名称、收货地址、做货日期（开始+结束）、款式、数量、产品规格、面料材质、工艺、手提（材质：规格）、打样费、打样/大货天数、箱规、备注
   - 产品图片：支持上传/拖拽/多选/预览
5. 在线表格：VTable 公式引擎，根据款式自动切换模板

**订单信息字段说明**：

| 字段 | 类型 | 联动规则 |
|---|---|---|
| 客户名称 | 选择/输入 | 选择客户时自动填充收货地址（名称+电话+地址）；输入新名称保存时自动创建客户 |
| 收货地址 | 文本 | 选择客户时自动填充 |
| 做货日期 | 日期范围 | 开始日期+大货天数 → 自动计算结束日期 |
| 款式 | 下拉（6种） | 切换款式时在线表格自动切换对应模板 |
| 数量 | 数字 | 联动在线表格成品行数量 |
| 产品规格 | 文本 | 联动在线表格成品行宽*高*底 |
| 手提（材质：规格） | 合并字段 | 格式 `材质：规格`，编辑时按 `：` 拆分 |
| 单个卖价 | 数字 | 从表格公式读取，可手动覆盖 |

#### 3.2.3 订单状态流转

**状态定义**：

| 值 | 状态 | 进入条件 | 退回目标 | 时间节点 |
|---|---|---|---|---|
| 1 | 报价中 | 新建订单 | —（不可退回） | quoteTime |
| 2 | 打样中 | 报价中→下一节点 | 报价中 | sampleTime |
| 3 | 做货中 | 打样中→下一节点 | 打样中 | productionStartTime |
| 4 | 已发货未收款 | 做货中→下一节点 | 做货中 | shippingTime |
| 5 | 已发货已收款 | 已发货未收款→下一节点 | 已发货未收款 | paymentTime |
| 6 | 结束 | 已发货已收款→下一节点 | 已发货已收款 | endTime |

**特殊规则**：
- 报价中(1)和打样中(2)可直接进入结束状态(6)
- 结束状态(6)退回时回到已发货已收款(5)
- 进入/退回节点时自动记录对应时间节点

#### 3.2.4 订单号生成规则

格式：`客户名称-时间戳-款式`

- 时间戳：14 位 `YYYYMMDDHHMMSS`，创建时生成
- 客户名称或款式修改时，保留原时间戳，重新拼接订单号

#### 3.2.5 在线表格（VTable-Sheet）

**款式与模板对应关系**：

| 款式值 | 名称 | 模板行数 | 特征 |
|---|---|---|---|
| 1 | 无底无侧普通袋 | 10 行 | 底=0，正反面+手提 |
| 2 | 有底无侧普通袋 | 12 行 | 底>0，正反面+手提+底部 |
| 3 | 有底有侧普通袋 | 12 行 | 正反面+侧底+手提 |
| 4 | 手提连底普通拼接袋 | 16 行 | 底部+正面+反面+外口袋+手提 |
| 5 | 手提连底高级拼接袋 | 14 行 | 底部+正反面+包边条+手提+阴阳手提 |
| 6 | 手提无连底拼接袋 | — | 手提无连底结构 |

**表格结构**：
- 列：参数输入列(col 1-6) / 中间计算列(col 7-10) / 结果列(col 11+)
- 样式：标题行（第一列无值其他列有值）蓝底白字，其余行无背景色；所有单元格加粗、字号+4
- 公式引擎：VTable-Sheet 内置 formulaManager，支持级联重算

## 6. 约束与规则

1. 金额字段统一保留两位小数（`toFixed(2)`）
2. 利润率按百分比计算：`refPriceNoTax = unitCost × (1 + profitRate)`
3. 成品行宽高修改时同步更新所有正反面行的宽高
4. `frontBackRows` 数组不能为空，否则 API 返回 400
5. 订单状态必须通过按钮操作流转，不能直接设置
6. 在线表格样式：标题行蓝底白字，间色格式已移除，其余行无背景色
