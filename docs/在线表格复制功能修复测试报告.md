## 一、问题背景

### 用户反馈

生产环境（HTTP 非安全上下文）中，在线表格应用存在两个复制功能异常：

1. **单单元格无法复制**：选中单个单元格按 Ctrl+C 后，剪贴板无内容写入，粘贴无效
2. **整行复制丢失公式**：选中整行复制后，粘贴内容中公式单元格变为计算值（如 `0`），公式字符串（如 `=B6*F6`）丢失

### 根因分析

| 问题 | 根因 | 代码位置 |
|------|------|----------|
| 单单元格无法复制 | HTTP 环境下 `navigator.clipboard` API 不可用（非安全上下文），VTable-Sheet 内部 fallback 到 `document.execCommand('copy')` + 隐藏 textarea 路径，在 canvas 焦点下常失败 | VTable-Sheet 内部 `handleCopy` |
| 整行复制丢失公式 | VTable-Sheet 默认只配置了 `keyboardOptions.getCopyCellValue.html`（HTML 模式带公式），未配置 `.value`，导致纯文本模式复制的是计算值而非公式字符串；而 fallback 路径只写 `text/plain`，HTML 模式的公式根本没用上 | VTable-Sheet `keyboardOptions` 默认配置 |

## 二、修复方案

### 修复 A：覆盖 `getCopyCellValue.value`

在 `src/utils/clipboardCopyEnhancer.ts` 中，覆盖 VTable-Sheet 的 `keyboardOptions.getCopyCellValue.value`，使纯文本模式也返回公式字符串：

```typescript
const formulaAwareValue = (col: number, row: number): any => {
  if (fm?.getCellFormula) {
    const formula = fm.getCellFormula({ sheet: sheetKey, row, col })
    if (formula) return formula  // 公式单元格返回公式字符串
  }
  return activeTable.getCellValue(col, row)  // 普通单元格返回值
}
ko.getCopyCellValue = {
  value: formulaAwareValue,           // 修复：纯文本模式也带公式
  html: originalHtml || formulaAwareValue,
}
```

### 修复 B：HTTP 环境接管剪贴板写入

在 `navigator.clipboard` 不可用时，主动拦截 `keydown` Ctrl+C 并通过 `copy` 事件直接写入 `e.clipboardData`，同时写 `text/plain` 和 `text/html`：

```typescript
const onKeyDown = (e: KeyboardEvent) => {
  if (!needsClipboardOverride()) return       // HTTPS 环境不介入
  if (!(e.ctrlKey || e.metaKey) || ...) return
  if (target是INPUT/TEXTAREA) return          // 编辑器内不拦截
  if (无选区) return
  e.preventDefault()
  e.stopPropagation()
  element.dispatchEvent(new ClipboardEvent('copy', { bubbles: true, cancelable: true }))
}

const onCopy = (e: ClipboardEvent) => {
  e.preventDefault()
  e.clipboardData.setData('text/plain', plainData)  // 含公式
  e.clipboardData.setData('text/html', htmlData)     // Excel 粘贴用
}
```

### Mock 策略

单元测试通过 `createMockTable()` 构造轻量 mock，模拟 VTable-Sheet 的 ListTable 接口：

- `formulaManager.getCellFormula()` — 模拟公式查询
- `getCellValue()` — 模拟普通值读取
- `getCopyValue()` — 模拟选区遍历拼接 tab+换行
- `stateManager.select.ranges` — 模拟选区状态

### 测试环境 Polyfill

jsdom 不提供 `ClipboardEvent` 构造函数（真实浏览器含 HTTP 环境均内置），在 `tests/setup.ts` 中添加 polyfill：

```typescript
if (typeof (globalThis as any).ClipboardEvent === 'undefined') {
  class ClipboardEventPolyfill extends Event {
    clipboardData: any
    constructor(type: string, eventInitDict?: EventInit & { clipboardData?: any }) {
      super(type, eventInitDict)
      this.clipboardData = eventInitDict?.clipboardData ?? createDataTransfer()
    }
  }
  ;(globalThis as any).ClipboardEvent = ClipboardEventPolyfill
}
```

> **注意**: 此 polyfill 仅用于测试环境。生产代码中 `ClipboardEvent` 由浏览器原生提供，HTTP 环境同样可用。
