# 订单 Excel 导出功能文档

## 功能概述

订单管理系统提供两种 Excel 导出模式：

1. **订单列表导出**（订单管理页面）：将当前筛选结果导出为格式化 Excel，包含全部订单字段、状态标签、价格信息和汇总统计。
2. **单订单 + 在线表格导出**（订单详情页面）：导出单个订单的完整信息 + 在线表格数据（保留 Excel 公式）。

## 使用方式

### 1. 订单列表导出

1. 进入「订单管理」页面
2. 使用搜索、状态、客户、款式筛选器筛选目标订单
3. 点击右上角「导出 Excel」按钮
4. 在确认对话框中查看导出范围和订单数量
5. 点击「确认导出」，等待下载完成
6. 文件名格式：`OrderExport_YYYYMMDDHHMMSS.xlsx`

### 2. 单订单 + 在线表格导出

1. 进入任意订单详情页面（需已保存）
2. 点击顶部「导出 Excel」按钮
3. 系统将导出订单信息 + 在线表格（含公式）
4. 文件名格式：`Order_客户名称_YYYYMMDDHHMMSS.xlsx`

### 汇总统计工作表

- 总订单数
- 总数量
- 总成本价（成本价 × 数量）
- 总含税价（含税价 × 数量）
- 销售总额(不含税)（单个卖价(不含税) × 数量，汇总）
- 销售总额(含税)（单个卖价(含税) × 数量，汇总）
- 利润总额(不含税)（(单个卖价(不含税) - 成本价) × 数量，汇总）
- 利润总额(含税)（(单个卖价(含税) - 含税价) × 数量，汇总）
- 订单状态分布（各状态订单数）

> **计算精度说明**：所有总额与利润计算均以**保留 2 位小数**的基础价格（成本价、含税价、单个卖价）为计算基础（`round2 = Math.round(n × 100) / 100`），确保行级单元格与汇总统计数值一致，避免浮点精度导致的尾数偏差。

### 单订单导出内容

- **工作表1「订单信息」**：按分组展示订单全部字段（基本信息、材料工艺、价格信息、时间节点、其他）+ 产品图片嵌入底部
  - 价格信息组包含：成本价、含税价、单个卖价(不含税/含税)、单个利润(不含税/含税)、销售总额(不含税/含税)、利润总额(不含税/含税)、单价、打样费、打样天数、大货天数
  - 产品图片：所有图片在**同一行水平排列**，不显示图片名称标签；按原始宽高比等比缩放（最大 180×180px），通过 fractional col 精确定位实现并排展示，无需修改列宽；支持 PNG/JPEG 格式，从 base64 data URI 解码嵌入
- **工作表2「在线表格」**：在线表格的完整数据 + 公式（公式在 Excel 中打开时自动重算）

### 价格计算公式

所有价格相关字段均自动计算，无需手动维护。计算以保留 2 位小数的基础价格为基准：

| 字段 | 公式 |
|------|------|
| 含税价 | 成本价 × 1.1（可手动覆盖） |
| 单个利润(不含税) | 单个卖价(不含税) - 成本价 |
| 单个利润(含税) | 单个卖价(含税) - 含税价 |
| 销售总额(不含税) | 数量 × 单个卖价(不含税) |
| 销售总额(含税) | 数量 × 单个卖价(含税) |
| 利润总额(不含税) | (单个卖价(不含税) - 成本价) × 数量 |
| 利润总额(含税) | (单个卖价(含税) - 含税价) × 数量 |

> 联动更新：当成本价、含税价、单个卖价、数量任一发生变化时，所有相关计算字段即时重新计算。

| 数字右对齐 | 价格、数量列右对齐 |

| 细边框 | 所有单元格带浅灰色边框(#D0D0D0) |
| 公式保留 | 在线表格公式直接写入 Excel，打开时自动重算 |

### API 端点

#### POST /api/export/orders

导出订单列表。

**请求体：**
```json
{
  "orderIds": ["quote-001", "quote-002"]
}
```
- `orderIds` 为空数组时导出全部订单

**响应：** Excel 文件流（`application/vnd.openxmlformats-officedocument.spreadsheetml.sheet`）

#### POST /api/export/order-with-table

导出单订单 + 在线表格。

**请求体：**
```json
{
  "orderId": "quote-001",
  "tableData": {
    "data": [["成品", 7200, 38, 40, ...], ...],
    "formulas": { "B3": "=B2", "H3": "=F3+C3", ... }
  }
}
```

**响应：** Excel 文件流

## 错误处理

| 场景 | 处理方式 |
|------|---------|
| 无可导出订单 | 返回 400 + 错误提示 |
| 订单不存在 | 返回 404 |
| 缺少表格数据 | 返回 400 |
| 生成 Excel 失败 | 返回 500 + 错误详情 |
| 网络中断 | 前端 catch + 错误提示 |
| 未保存订单导出 | 前端禁用导出按钮 + tooltip 提示 |
